## Contratto dei deck

Ogni deck usa la stessa sequenza di massima:

`richiamo → obiettivi → modello mentale → esempio → errore tipico → checkpoint → progetto/lab → recap → prossimo passo`

Le slide non sostituiscono il testo canonico: servono per condurre la spiegazione e passare rapidamente dalla teoria all'osservazione/laboratorio.
